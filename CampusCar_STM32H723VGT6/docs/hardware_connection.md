# 硬件连接说明

## 引脚定义

### UART接口

#### UART1 - NUC通信（命令接收）
| 引脚 | 功能 | 连接目标 |
|------|------|---------|
| PA9  | TX   | NUC USB串口转换器 RX |
| PA10 | RX   | NUC USB串口转换器 TX |
| 波特率 | 115200 | - |

**协议格式**：8字节Hoverboard协议
- 帧头：0xABCD
- 数据：steer (int16), speed (int16)
- 校验：XOR

#### UART7 - 电调通信（命令发送）
| 引脚 | 功能 | 连接目标 |
|------|------|---------|
| PE7  | RX   | 电调 USART2 TX (PA2) |
| PE8  | TX   | 电调 USART2 RX (PA3) |
| 波特率 | 115200 | - |

**协议格式**：26字节Hoverboard扩展协议
- 支持速度、转向控制
- 包含反馈数据

### PWM接口

#### TIM2_CH1 - 舵机控制
| 引脚 | 功能 | 连接目标 | 说明 |
|------|------|---------|------|
| PA0  | PWM  | MG996R信号线（橙/黄） | 50Hz, 0.5~2.5ms |

**舵机供电**：
- VCC（红线）→ 独立5V/6V电源（≥2A）
- GND（棕/黑线）→ STM32 GND（共地）
- 信号（橙/黄线）→ PA0

⚠️ **注意**：舵机电源必须独立供电，不能直接从STM32 3.3V或5V供电！

### GPIO - LED指示灯

| 引脚 | 功能 | 说明 |
|------|------|------|
| PC13 | LED1 | 启动测试指示（闪烁4次）+ 命令接收指示 |
| PC14 | LED2 | 主循环心跳指示（500ms周期） |
| PC15 | LED3 | 预留 |

## 硬件连接检查清单

### 上电前检查
- [ ] STM32供电正常（USB或外部5V）
- [ ] 电调电池已连接且电压正常
- [ ] 舵机独立电源已连接（5-6V）
- [ ] 所有GND共地
- [ ] UART1和UART7接线正确（TX↔RX交叉）

### 接线验证
```bash
# 检查NUC端串口设备
ls /dev/ttyUSB* /dev/ttyACM*

# 测试串口通信
sudo minicom -D /dev/ttyUSB0 -b 115200
```

## 电气特性

### 电源需求
| 模块 | 电压 | 电流 | 说明 |
|------|------|------|------|
| STM32H723 | 3.3V | ~200mA | USB供电或外部5V经LDO |
| 舵机MG996R | 4.8-6V | 峰值2.5A | 必须独立供电 |
| 电调 | 电池电压 | 视负载 | 通常12-24V |

### 信号电平
- STM32 GPIO输出：3.3V CMOS
- 舵机信号输入：兼容3.3V/5V
- UART通信：3.3V TTL（如果NUC端是5V需要电平转换）

## 常见连接问题

### 问题1：串口无通信
**症状**：发送数据无响应
**检查**：
1. TX和RX是否交叉连接
2. 波特率是否匹配（115200）
3. GND是否共地
4. 串口设备权限（`sudo chmod 666 /dev/ttyUSB0`）

### 问题2：舵机不动
**症状**：舵机无响应或抖动
**检查**：
1. 独立电源电压是否足够（≥4.8V）
2. 信号线是否连接到PA0
3. GND是否共地
4. 用示波器测PA0是否有50Hz PWM

### 问题3：电调无响应
**症状**：电机不转
**检查**：
1. 电调供电是否正常
2. UART7与电调连接是否正确
3. 电调是否已正确初始化
4. 用示波器查看PE8是否有数据输出

## 安全注意事项

⚠️ **警告**
1. 舵机必须使用独立电源，禁止从STM32取电
2. 电调电池极性不可接反
3. 首次上电建议断开电机连接，确认控制信号正常后再连接
4. 调试时注意防止短路

## 测试工具推荐

- **万用表**：测量电源电压
- **示波器/逻辑分析仪**：查看UART和PWM波形
- **USB转TTL模块**：监控UART通信
- **minicom/cutecom**：Linux串口调试工具
